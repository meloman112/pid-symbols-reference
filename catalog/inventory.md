# Перечень элементов P&ID по стандартам

Что есть в стандартах, сколько разновидностей, что уже в базе и откуда.

## Модель разновидностей

Символ арматуры собирается из независимых осей, а не рисуется на каждую комбинацию:

| Ось | Значения |
|---|---|
| Корпус | задвижка, вентиль/клапан, кран, затвор поворотный, мембранный, игольчатый, пережимной |
| Форма | проходной, угловой, трёхходовой, четырёхходовой |
| Функция | запорный, регулирующий, обратный, предохранительный, редукционный, дроссельный |
| Привод | ручной, электрический, электромагнитный, мембранный, поршневой, электрогидравлический |
| Положение при отказе | FO/открывает, FC/закрывает, FL/сохраняет, FI, FL/DO, FL/DC |
| Доп. | ручной дублёр, позиционер |

«Климатический клапан» отдельным символом не существует: это регулирующий клапан с электроприводом в контуре TIC.
В ГОСТ 2.785 привод не входит — п. 3 стандарта: вид управления добавляется комбинированием с другими стандартами ЕСКД.

ГОСТ 2.788–2.795 рисовали агенты по сканам и сверяли на глаз. Приблизительны мелкие детали внутри символов:
штриховка и рёбра (пластинчатые, регенеративные теплообменники), пламя, внутренности фильтров 2.793 п. 9,
стрелки вращения у барабанных и роторных сушилок, «петля» ленточной сушилки, наклон ротационного питателя.

Буквенные коды: таблица `letters` — ГОСТ 21.208 табл. 2 сверена с текстом дважды (первая выборка сдвинула колонку D); ISA 5.1 — по памяти, сверить.

## Описания

Все поля «назначение / где ставить / ошибки / похожие» написал Haiku по названию и кратким фактам из стандартов,
без сверки с полными текстами. Инженер правит через «Исправить» в вебе.

## Дальше

1. ISA: регуляторы прямого действия, ПАЗ, первичные элементы T/P — нужен источник.
2. ГОСТ 2.785 п. 14–29 — если инженеру нужны сантехника или судостроение.
3. Типовые узлы: сделаны 3 (клапан с обвязкой, насосы, контур уровня). Дальше — теплообменник с TIC, PSV, расходомер, отбор давления, отсечка ПАЗ.
   Состав узлов — инженерная практика, не текст стандарта; проверить инженеру.
4. Инженеру пройтись по ГОСТ 2.788–2.795 и поправить неточные рисунки.
